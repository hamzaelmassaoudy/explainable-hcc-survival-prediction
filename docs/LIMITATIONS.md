# Limitations

The intended study is limited to 165 patients from one source, with substantial missingness
and no external test cohort. Any repeated cross-validation estimates will be uncertain;
calibration slope/intercept can be unstable, and subgroup metrics may need to be suppressed.
If candidate models are selected and reported from the same out-of-fold evidence,
model-selection optimism remains possible. Variables are associations, not causes. Any final
all-data model would be a research demonstration only and would not be clinically validated.
