# Code of Conduct

## Our standards

Contributors are expected to be respectful, constructive, and mindful that this project
concerns health data. Welcome good-faith questions, give technically specific feedback, and
acknowledge uncertainty in research claims.

Unacceptable behavior includes harassment, discriminatory language, personal attacks,
sharing identifiable health information, submitting medical advice, or presenting the project
as clinically validated.

## Scope and enforcement

This code applies to project spaces and contribution discussions. Maintainers may remove,
edit, or reject contributions that do not meet these standards. For sensitive safety, privacy,
or security concerns, use the reporting route in [SECURITY.md](SECURITY.md) and do not include
sensitive details in a public issue.
